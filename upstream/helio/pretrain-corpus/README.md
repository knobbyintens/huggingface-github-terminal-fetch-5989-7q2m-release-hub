# Helio Pretrain Corpus

Raw web-crawl shards produced by the Helio pretraining data pipeline. This is a
pretraining corpus, not a dialogue or instruction set.

File `helio_web_crawl_v4.jsonl` schema: doc_id, url, text, lang, crawl_ts. The file
contains 120 archived documents.
