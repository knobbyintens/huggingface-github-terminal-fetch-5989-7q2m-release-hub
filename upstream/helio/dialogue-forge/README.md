# Helio Dialogue Forge

Assembly workspace for the final Helio dialogue corpus. The shard in this publication
is the final assembled dialogue corpus produced by the Helio program.

File `aster_sft_v1.chat.jsonl` schema: conversation_id, turn_index, role, content,
token_count, source_doc_id. The shard contains 200 dialogue turns.
